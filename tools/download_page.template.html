Install

  1. Install Fabric Loader for 1.21.11 with the Fabric installer.
  2. Start the fabric-loader-1.21.11 profile once, then close the game.
  3. Put Fabric API and the Aqua jar in your mods folder:
    • Windows: %APPDATA%\.minecraft\mods
    • macOS: ~/Library/Application Support/minecraft/mods
    • Linux: ~/.minecraft/mods
  4. Start the Fabric profile and press Right Shift to open the Aqua menu.

What’s inside

  • Fern-style HUD with a drag-and-drop editor, and a new menu and title screen
  • Wardrobe: original 3D skins, wings, hats, capes, knife skins, emotes and kill effects
  • Music player for your own .ogg files, with synced lyrics found automatically
  • Zoom, Name Protect, Skin Protect, screenshot notifications, profiles and themes

No cheats: no combat, movement, x-ray, ESP or other unfair features. Cosmetics are only visible to you. Check each server’s rules before you play.
